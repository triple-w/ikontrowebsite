# Recursos de marca iKontrol

Los archivos `logo.svg` e `icon.svg` son identificadores vectoriales temporales
para que el sitio no tenga imágenes rotas.

Cuando estén disponibles los archivos oficiales:

- agregar `logo.png` en esta carpeta;
- agregar `icon.png` en esta carpeta;
- sustituir en `index-4.html` e `index-3.html` las referencias a `.svg` por `.png`.

Las fotografías reales de máquinas se agregan dentro de `autocobro/`.
